Nova importação

A importação grava primeiro os preços válidos de SP do CSV e depois consulta as páginas da API de revendedores da ANP para atualizar as coordenadas por CNPJ. Uma falha na API não desfaz os preços importados.

Uma carga parcial pode ser retomada repetindo a mesma URL e período; postos e preços são atualizados de forma idempotente.
